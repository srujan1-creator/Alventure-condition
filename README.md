# AI-Powered WhatsApp Message Notification Router

An intelligent, multi-stage, personalized notification routing system built for WhatsApp messages. The system reviews every incoming multimodal message and decides whether it should interrupt the user immediately (`notify`), be batched into a daily digest (`digest`), or be suppressed silently (`mute`).

## Problem Overview & System Goals

WhatsApp users face notification overload from diverse channels: family groups, society updates, workplace messages, commercial promotions, image posters, voice notes, and dangerous scams.

This system solves this challenge by making personalized decisions based on:
1. **Multimodal Content**: Text, image OCR/visual descriptions, and voice note transcripts.
2. **User Context & Preferences**: Quiet hours schedule, reply/open history, report sensitivity, and mute preferences.
3. **Group Dynamics**: Admin roles, group mute states, and direct mentions (`@user`).
4. **Business Reputation & History**: Verified sender domain, account age, report history, and prior transaction history (orders, bookings, payments, opt-ins/opt-outs).
5. **Historical Interactions**: Semantic similarity matching with past messages (`evidence_message_ids`).

---

## Required Output Schema

For every incoming message in `dataset/messages.csv`, the router generates a prediction in `output.csv` with the following columns:

| Column | Allowed Values / Format | Description |
| :--- | :--- | :--- |
| `message_id` | String | Unique identifier of the incoming message |
| `action` | `notify`, `digest`, `mute` | Final routing decision |
| `message_type` | `personal`, `urgent`, `event`, `payment`, `business_update`, `promotion`, `greeting`, `forward`, `spam`, `scam`, `unknown` | Best-fit message category |
| `reason` | Text string | Short human-readable explanation of the routing logic |
| `confidence` | Float [0.0 - 1.0] | Calibrated decision confidence score |
| `evidence_message_ids` | Semicolon-separated IDs or `none` | Historical message IDs used as contextual evidence |

## System Architecture & Routing Logic

```
                      [ Incoming Message ]
                                |
              +-----------------+-----------------+
              |                 |                 |
         [ Text Msg ]     [ Image Poster ]  [ Voice Note ]
              |                 |                 |
              |            (OCR & Desc)    (Audio Transcript)
              +-----------------+-----------------+
                                |
                    [ Multimodal Processor ]
                                |
                  [ Context Graph & Features ]
           (Quiet Hours, Group Admin, Biz Trust, History)
                                |
                    [ Multi-Stage Router Engine ]
                                |
       +------------------------+------------------------+
       |                        |                        |
[ Stage 1: Scam Guard ] [ Stage 2: Urgency/OTP ] [ Stage 3: Personal/Digest ]
       |                        |                        |
(Mute + Scam/Spam)     (Notify + Urgent)        (Digest / Mute)
       +------------------------+------------------------+
                                |
                    [ Evidence Retriever ]
                                |
                 [ Calibrated Output Synthesizer ]
                                |
                         [ output.csv ]
```

## File Structure

```
.
├── dataset/                        # Dataset tables (autogenerated if missing)
│   ├── messages.csv                # Incoming target messages to route
│   ├── sample_messages.csv         # Sample ground truth messages
│   ├── users.csv                   # User behavior & quiet hours
│   ├── groups.csv                  # Group metadata & activity
│   ├── group_members.csv           # User-group relationships & mute state
│   ├── business_accounts.csv       # Business verification & report history
│   ├── user_business_history.csv   # Recent transactions & opt-ins/opt-outs
│   ├── message_history.csv         # Past messages
│   ├── message_events.csv          # Past message reactions (opened, replied, reported)
│   ├── images.csv                  # Image OCR & description metadata
│   ├── voice_notes.csv             # Voice note transcript & audio metadata
│   ├── daily_notification_summary.csv
│   └── output.csv                  # Submission output template
├── src/
│   ├── dataset_generator.py        # Synthetic dataset generator for out-of-the-box execution
│   ├── data_loader.py              # Relational context loader & indexer
│   ├── multimodal_processor.py     # Text, OCR & audio transcript parser
│   ├── feature_extractor.py        # Contextual feature engineering engine
│   ├── evidence_retriever.py       # Historical evidence matcher
│   ├── router_engine.py            # Multi-stage routing decision engine
│   └── evaluator.py                # Performance benchmarking tool
├── tests/
│   └── test_router.py              # Automated unit test suite
├── run_pipeline.py                 # Main execution pipeline runner
├── package_submission.py           # Output validator & submission packager
├── output.csv                      # Final predicted routing output
└── code.zip                        # Submission source code package
```

## How to Run

1. **Execute Complete Pipeline**:

